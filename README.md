# Расчёт ростверка на продавливание

Расчёт плитной части свайного ростверка на продавливание колонной и угловой (крайней) сваей,
по поперечной силе, на изгиб и местное сжатие с выгрузкой отчёта Word (.docx) для РПЗ.

Нормативная база: Пособие по проектированию железобетонных ростверков свайных фундаментов под колонны,
СП 63.13330.2018 (с Изм. № 1, 2), СП 24.13330.2021, СП 45.13330.2017.

## Как пользоваться

- Онлайн: откройте страницу GitHub Pages этого репозитория (ссылка — в разделе «About» справа).
- Без интернета: скачайте файл `index.html` и откройте его в браузере — все библиотеки встроены в файл.

Расчёт выполняется в браузере, исходные данные никуда не отправляются.
